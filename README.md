# Pegazus Robot

Desktop trading robot for Pegazus platform.

## Download
Go to [Releases](https://github.com/olivia20266/pegazus-robot/releases) and download:
- **Windows**: `Pegazus-Robot-Setup.exe`
- **Mac**: `Pegazus-Robot.dmg`
- **Linux**: `Pegazus-Robot.AppImage`

## Usage
1. Download and install
2. Sign in with your Pegazus account
3. Configure robot settings (EMA, SL, TP)
4. Click **Start Robot**
5. Robot runs in background 24/7
